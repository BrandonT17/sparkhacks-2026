# Qupa - AI-powered Fashion Tool

> made by brandon thach, syed daanish ismail, phillip pham, omar khan

an AI-powered fashion assistant that helps deload the process of searching for clothes online based on their preferences and values. 

## Stack

- frontend
    - next.js
    - javascript/typescript
    - tailwind
    - shadcn ui library

- backend
    - clerk auth
    - serpAPI web scraper
    - gemini API

## Functionality

- ai-powered clothing search based on user preferences
- ai-powered style recommendations
- search filter by category
- "ethical shopping" filter to filter-out unethical brands
- mutli-brand results
